# Function Calling 실습하기 (Self-study)

## 실습 구조
LLM은 사전에 학습된 데이터를 기반으로 응답하기 때문에 실시간 데이터가 필요한 경우에는 적절한 답변을 할 수 없다. Spring AI에서는 이러한 한계를 극복하기 위해 Function Calling이라는 기능을 제공한다.

Function Calling은 LLM이 특정 작업을 처리 할 때 등록 해 둔 Function과 연관 된 작업이라고 생각되면 해당 Function을 호출하여 필요한 작업을 수행하는 구조이다. 
![1.png](img%2F07%2F1.png)

위 그림을 설명하자면 다음과 같다. 
1. 사용자의 질문 내용이 Spring 시스템에 입력이 되면, 이를 LLM에게 전달한다. 이때, 사용 가능한 Function 정보도 함께 전달한다.
2. LLM은 사용자의 질문 내용을 보고 Function Calling이 필요한지 판단 하게 된다. 필요하다고 판단되면 어떤 Function Calling을 수행할지 Spring 시스템에 전달한다. 
3. Spring 시스템은 Function을 호출하여 필요한 작업을 수행하고 결과를 받는다. 
4. 받은 결과를 다시 LLM에게 전달하여 최종적인 사용자 응답을 만들어 내도록 한다. 
5. 최종 응답을 출력한다. 


이번 실습에서는 Function Calling을 사용하여 실시간 환율 정보를 제공하는 API를 개발하는 실습을 해 보도록 하겠다. 

## 구현 순서
1. Function Calling을 위한 Request/Response 모델 생성
2. 외부 API 호출을 처리할 Function 구현
3. Function을 Spring Bean으로 등록하기 위한 Config 작성
4. Controller를 통한 API 엔드포인트 제공

## Function 구현

다음은 실제로 네이버 금융 API를 호출하여 환율 정보를 가져오는 Function을 구현하자.

| 패키지 경로                           | 파일이름                 |
|----------------------------------|----------------------|
| com.samsungsds.springai.function | ExchangeRateFunction |

**ExchangeRateFunction.java**
```java
package com.samsungsds.springai.function;

import com.samsungsds.springai.model.ExchangeRateRequest;
import com.samsungsds.springai.model.ExchangeRateResponse;
import org.springframework.web.client.RestTemplate;
import java.util.function.Function;

public class ExchangeRateFunction implements Function<ExchangeRateRequest, String> {
    private static final String NAVER_EXCHANGE_API_URL =
            "https://m.stock.naver.com/front-api/marketIndex/productDetail?category=exchange&reutersCode=FX_USDKRW";
    private final RestTemplate restTemplate;

    public ExchangeRateFunction() {
        this.restTemplate = new RestTemplate();
    }

    @Override
    public String apply(ExchangeRateRequest request) {
        try {
            ExchangeRateResponse response = restTemplate.getForObject(NAVER_EXCHANGE_API_URL, ExchangeRateResponse.class);

            if (response == null || !response.isSuccess()) {
                return "Failed to fetch exchange rate data";
            }

            ExchangeRateResponse.ExchangeResult result = response.result();
            String direction = result.fluctuationsType().text();
            String fluctuation = result.fluctuations();
            String rate = result.closePrice();
            String time = result.localTradedAt().replace("T", " ").substring(0, 16);

            return String.format(
                    "현재 달러/원 환율: %s원 (%s %s원)\n거래 시각: %s",
                    rate,
                    direction,
                    fluctuation,
                    time
            );
        } catch (Exception e) {
            return "Exchange rate data fetch failed: " + e.getMessage();
        }
    }
}


```
Function인터페이스는 함수형 프로그래밍을 지원하기 위한 인터페이스로, 입력과 출력, 그리고 실제 함수의 동작을 정의하게 된다.
형태는 `Function<입력, 출력>`형식이고 `apply` Method를 재정의 해 줌으로 해서 동작을 정의한다. 
여기서는 `Function<ExchangeRateRequest, String>` 인터페이스를 구현하여 LLM이 호출할 수 있는 형태로 만들었다.
 


네이버 금융 API를 호출하여 현재 환율 정보를 가져오고, 이를 사용자가 이해하기 쉬운 형태의 문자열로 변환하여 반환한다.


## Controller 구현

마지막으로 사용자의 질문을 받아 LLM에게 전달하고, 필요한 경우 Function을 호출하여 응답을 생성하는 Controller를 구현하자.

| 패키지 경로                             | 파일이름               |
|------------------------------------|--------------------|
| com.samsungsds.springai.controller | ExchangeController |

**ExchangeController.java**
```java
package com.samsungsds.springai.controller;

import com.samsungsds.springai.function.ExchangeRateFunction;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.*;

@RestController
public class ExchangeController {

    private final ChatClient chatClient;

    public ExchangeController(ChatClient chatClient) {
        this.chatClient = chatClient;
    }

    @PostMapping("/ask-exchange")
    public String askExchangeRate(@RequestParam String question) {

        return  chatClient.prompt()
                .user(question)
                .function("exchangeRate", "현재 원화/달러 환율을 조회 해 온다. (USD/KRW만 지원)", new ExchangeRateFunction())
                .call()
                .content();

    }
}
```

`.function`항목을 통해 LLM에게 function을 넘겨 주게 된다. 

첫번째 인자는 LLM이 호출할 함수의 이름이 들어가고, 두번째 항목에는 설명이 들어간다. 이 설명에 기반에서 LLM이 이 function을 호출 할지를 결정 하게 된다. 

마지막 항목에 Function을 생성해서 입력 해 준다. 

Function을 Bean으로 생성 해 놓고 Bean의 이름을 넣어주는 방식도 있으나 이는 Bean이름이 String으로 들어가기 때문에 향후 변경에 취약하고, 현재 버전에서 함수형의 Bean을 사용하는 부분이 불안정 하여 이와같이 구현 하였다. 

이로써 LLM은 사용자의 질문을 분석하여 환율 정보가 필요하다고 판단되면 자동으로 `exchangeRate` 함수를 호출하게 된다.
